# CSR Group of Companies – Corporate Website

A premium, modern, responsive multi-page corporate website for **CSR Group of Companies**, inspired by classic Indian corporate heritage and the brand ethos:
> *"Stay Strong, Stay Healthy"*  
> *"Goodness in Every Box..."*

---

## 🏛️ Executive Company Overview

**CSR Group of Companies** operates six distinct business divisions under one trusted corporate umbrella. The website presents a unified corporate identity uniting dairy purity, fresh orchard produce, farm vegetables, high-protein athletic nutrition, wholesome home-style meal boxes, and sacred devotional essentials.

> **Important Notice:** This is an **informational corporate website**, NOT an e-commerce store.  
> It intentionally features zero shopping carts, checkouts, online payments, or order transaction engines. Product categories and specifications are presented for corporate information, trade inquiries, institutional tenders, and doorstep subscription coordination.

## 🚀 Installation & Execution

### 1. Prerequisites
Ensure **Node.js (v18+)** and **npm** are installed on your system.

### 2. Install Dependencies
```bash
npm install
```

### 3. Launch Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
Creates an optimized production bundle in the `dist/` directory.

### 5. Preview Production Build
```bash
npm run preview
```

### 6. Lint Code
```bash
npm run lint
```
